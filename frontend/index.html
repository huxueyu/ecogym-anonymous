Platform Operation Bench

Human study interface for collecting human-operator trajectories (performance baseline)

1 Start Backend Service
Run the following command in your terminal to start the backend service:
cd frontend
python3 operation_server.py
Or use the helper script:
./start_operation_bench.sh

start_operation_bench.bat
2 Confirm Service Running
Make sure you see output similar to the following:
Platform Operation Bench — human study server
Listening on http://localhost:5001
Open http://localhost:5001/ or operation_bench.html after the server is running.
3 Open study interface
After the server responds on the health check, open the web interface (served from the same process on port 5001, or open operation_bench.html while the server is running).
Task summary: As a platform operator, you need to maximize DAU (Daily Active Users) within 365 days while balancing content quality, creator ecosystem, and user retention. You can execute 1 operation action per day, then observe the natural evolution of the platform.
